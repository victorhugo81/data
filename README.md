# Sample Data Repository

This repository is intended to hold reusable sample data for different projects, prototypes, demos, tutorials, and learning exercises.

It can be used for:
- SQL and database practice
- ETL and data pipeline experiments
- Application demos and mock datasets
- Data visualization and analytics examples
- Portfolio and personal project data exploration

## Repository contents

- [sql-interview-questions/](./sql-interview-questions) — sample SQL interview questions and related data for practice and demonstrations

## Notes

- Data in this repo is meant for examples and experimentation.
- Use synthetic, anonymized, or non-sensitive data when possible.
- You can copy, transform, or extend the files to fit the needs of your own project.

## Purpose

The goal of this repo is to keep a central place for reusable sample data that can be used across multiple projects without having to recreate datasets each time.
